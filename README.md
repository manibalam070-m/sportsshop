# Sportiva React Sports Shop

Frontend-only sports shop built with ReactJS, HTML, CSS and JavaScript.

Features: responsive UI, search, sport filters, product cards, add-to-cart, quantity controls, cart totals and demo checkout.

Run:
1. Install Node.js LTS.
2. Extract this ZIP.
3. Open terminal in the project folder.
4. `npm install`
5. `npm run dev`

Customize products in `src/main.jsx` and styling in `src/styles.css`.
